# RK3566 target transfer — September 24, 2026

The author connected Orange Pi 3B and requested acceptance-relevant validation.
This implements the primary target of the already frozen transfer protocol;
it does not select a new target after favorable Radxa measurements.

RK3576 results are now known: 2.59% width24 and 2.72% FP16 lower mean complete
service time than the best fixed policy, positive in both sessions, with
individual regressions. No rule, feature, coefficient, mask, order, analysis
threshold, numerical tolerance or timing boundary is changed in response.

The accepted 19 RK3566 compiled graphs, catalogs, integer/FP16 precisions,
boundary variants and the previous numerical adapter are reused byte-for-byte.
Do not read target calibration fits into the new policy. The original width24
RK3576 donor coefficients apply to both graphs unchanged, with zero target
fitting or performance calibration. Existing target controls and RKNN runtime
must pass fresh read-only verification and numerical qualification.

Two engineering sessions: the same eight previously opened masks, four
policies, two repeats =64 requests/graph. These establish numerical integrity,
not performance fitting. Reference selected outputs and bicubic fallback are
checked independently from the raw retained arrays before evaluation approval.

After engineering passes, freeze a target approval including both qualification
journal hashes and source closure. Evaluate width24/0, fp16/0, width24/1, fp16/1,
640 requests/session. Same 40 fresh geometries and request orders used on Radxa.
They are now observed there, so RK3566 is a controlled cross-device transfer
replication, not a new blind geometry population. All four cells were already
historically studied. The primary cell is seven-convolution FP16 RK3566, where
both network structure/precision and device differ from donor development.

Use 60 C start/block, <80 C operational abort, <=300s cooldown, <=180s owned
native-call watchdog, normal governors and a >=9,225,371,648-byte evidence
reserve. No overclocking, governor writes or unrelated process termination.
Keep the unchanged target-specific dual-node ownership proof and authenticated
RKNN file-descriptor checks; generic RK3576 occupancy checks are insufficient.
Record observed controls before acceptance or rejection. Export CPU-only
bicubic references using the board environment for byte-exact fallback checks.

Report whole-cell means, both sessions, both fixed controls and the simple
geometry heuristic, decision overhead, calibration cost, individual regressions
and deadlines. Positive transfer requires lower mean service than both fixed
policies in the primary target; disclose any session sign disagreement.
Do not infer statistical population generality from two sequential sessions.
No target fitting, run-until-positive, failed-sample replacement or silent
thermal amendment. Preserve every physical result, including failures.

Acceptance relevance: evidence that a bounded fragmentation characterization
supports useful out-of-donor execution choices. It is not a claim to a new
general scheduling algorithm, cross-vendor coverage or guaranteed publication.
